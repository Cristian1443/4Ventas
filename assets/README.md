# Assets de la Aplicación

Esta carpeta debe contener los iconos y splash screen de la aplicación.

Por ahora, Expo usará iconos por defecto. Puedes agregar los siguientes archivos más adelante:

## Archivos Necesarios

### icon.png
- Tamaño: 1024x1024 píxeles
- Formato: PNG con transparencia
- Uso: Icono principal de la app

### splash.png
- Tamaño: 1242x2436 píxeles (o mayor)
- Formato: PNG
- Uso: Pantalla de inicio

### adaptive-icon.png (Android)
- Tamaño: 1024x1024 píxeles
- Formato: PNG con transparencia
- Uso: Icono adaptativo para Android

### favicon.png (Web)
- Tamaño: 48x48 píxeles
- Formato: PNG
- Uso: Favicon para versión web

## Nota

**La aplicación funcionará sin estos archivos.** Expo usará sus iconos por defecto.

Puedes agregarlos más tarde cuando quieras personalizar la app.
